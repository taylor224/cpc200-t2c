# T2C Tesla UI 26101732

화질이 저절로 낮아지며 CarPlay가 끊기고 화면이 커지던 문제 수정, 전원이 끊겨도 어댑터 UI 로그 보존, 블루투스 인터넷 (재)연결 시 DNS 공백 제거.

- 페이지가 화질·프레임·전송 방식을 스스로 바꾸지 않습니다. 26101726까지는 Wi-Fi가 잠시 막히면 화질을 한 단계 낮췄고, 그때마다 CarPlay가 재시작되며 화면이 커졌습니다. 화면 크기와 UI 크기는 화질 5단계 하나로 합쳤고, 디코더가 못 따라가면 안내만 표시합니다.
- 업데이트 대화상자에 릴리스 노트가 표시됩니다(차 페이지, 폰 페이지). 차 페이지는 접속 30초 후와 6시간마다 새 버전을 확인해 홈 화면에 배너를 띄웁니다. 자동으로 설치하지는 않습니다. 펌웨어 업데이트 중 열려 있던 페이지는 한 번 스스로 새로고침합니다.
- 어댑터 UI 로그 끝부분을 플래시에 보관합니다. 2분마다, 그리고 CarPlay가 끊기면 15초 안에 끊긴 이유 줄(세션 종료, 어느 기기가 Wi-Fi를 떠났는지, DNS 상태)과 함께 저장합니다. 직전 부팅의 복사본도 남깁니다. 진단 항목: t2cui_saved, t2cui_prev, t2cd_log. 펌웨어 업데이트는 이 복사본을 지웁니다.
- 블루투스 인터넷(PAN) 연결 시 어댑터의 DNS 리다이렉트가 최대 20초 사라지던 문제를 없앴습니다. 그 사이 차의 인터넷 확인이 바로 실패해 LTE로 전환되고 CarPlay 페이지가 끊길 수 있었습니다(close 1006 후 "DNS 주소를 찾을 수 없음").
- 저장 로그에 핫스팟 비밀번호가 남지 않습니다.
- 알려진 문제: 블루투스는 연결된 채 iPhone이 어댑터 Wi-Fi만 떠나면 CarPlay가 스스로 돌아오지 않습니다. 어댑터 전원을 껐다 켜 주세요. 수정 작업 중입니다.
